#  Full-Stack TODO Application

FocusFlow is a minimalist productivity tool built to manage daily tasks. This project focusing on the **MERN stack** (MongoDB, Express, React, Node.js).

##  Project Structure
  **client/**: React frontend styled with Tailwind CSS, organized into modular components and pages.
  **server/**: Node.js/Express backend following a Model-Controller-Route architecture.

##  Tech Stack
  Frontend: React.js, Tailwind CSS
  Backend: Node.js, Express.js
  Database: MongoDB with Mongoose 
  State Management: React Hooks (Custom hooks for API interaction)
